ShopSphere Scheduled Jobs

Background maintenance, deployed separately from the API.

Abandoned cart cleanup
/api/cleanup-carts — deletes carts untouched for 30 days, cascading to their items.
Schedule
Daily at 03:00 UTC, invoked by Vercel Cron.
Access
The cleanup endpoint requires a bearer secret and returns 401 without one, so it cannot be triggered from a browser.
Public status
/api/status runs the same function and the same database connection without deleting anything, so the job can be seen executing without access to this Vercel account.
