ShopSphere Review Service

Product reviews, extracted from the monolith and deployed on its own.

Health

  • /api/health — checks the MongoDB connection

Endpoints

  • /api — service metadata
  • /api/products/:identifier/reviews — list, create, update, delete
  • /api/reviews/count — total, read by the admin dashboard

How it stays independent

  • Reviews live in its own MongoDB database.
  • Products are resolved over REST against the main API, not by a shared database.
  • Callers' tokens are forwarded to the main API for identity, so this service holds no signing secret and no PostgreSQL credential.
