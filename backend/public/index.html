ShopSphere API

The commerce backend. Products, carts, orders, and accounts.

Health

  • /api/health — checks PostgreSQL and MongoDB, and returns 503 if either is unreachable

Endpoints

  • /api — service metadata
  • /api/products · /api/categories
  • /api/auth · /api/users
  • /api/cart · /api/orders
  • /api/statistics · /api/activity-logs

Notes

  • Reviews are served by a separate deployment, not by this one.
  • Authenticated routes require a bearer token; requests are rate limited.
